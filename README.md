YouTube Video Transcript Extractor, Translator & Rewriter

## 🚀 Kaise Chalayein (BOHAT AASAN!)

### Step 1: Node.js Install Karein (Sirf Ek Baar)
1. Jayein: https://nodejs.org
2. Green "LTS" button click karein
3. Download file install karein (Next Next Finish)

### Step 2: START-APP.bat Double-Click Karein
- **Windows**: `START-APP.bat` double-click karein
- **Mac/Linux**: Terminal mein `./START-APP.sh` run karein

### Step 3: Browser Kholein
http://localhost:3000

---

## ⚠️ Agar Error Aaye:

### "execution policy" error:
PowerShell kholein (admin) aur type karein:
```
Set-ExecutionPolicy RemoteSigned
```

### Port 3000 busy:
Pehle se koi app chal raha hai port 3000 par. Band karein ya:
```
npx next dev -p 3001
```

### Database error:
Koi masla nahi! App bina database ke bhi chalega. Sirf history save nahi hogi.
